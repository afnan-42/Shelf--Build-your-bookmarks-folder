Your bookmarks

Chromium browsers only place folders straight on the bar when the bar is empty. Otherwise everything lands inside “Imported”.

How to import the file

Chrome, Edge, Brave, Helium and other Chromium browsers: Settings, Import bookmarks, choose “Bookmarks HTML file”. If your bookmarks bar already has items, the browser puts everything inside an “Imported” folder. To avoid that, empty the bar before importing, or drag the folders out of “Imported” afterwards.

Firefox: Bookmarks, Manage bookmarks, Import and Backup, Import Bookmarks from HTML.

Safari: File, Import From, Bookmarks HTML File.

Shelf builds the file on your device and sends nothing anywhere.
